# Schedules to import: top 30

Launch checklist item 2. Popular US bikes, roughly in priority order within
each make. Use **Add a schedule** on the admin page: pick the make and model,
enter the years, paste the link. "Also use for" is the import's editions
picker (same schedule copied to those models).

Model names are as they appear in the app's dropdowns. **New** means it isn't
in the list yet: choose Other / Not Listed and type it.

Before starting: test already has Rebel 300 and Rebel 500 (2025 only) and
Norden 901 (2025, 2026). Production may have others I couldn't check, so
skip anything already done there.

## How much to trust each link

- ✅ **Checked:** the link downloads a PDF (checked 2026-10-26).
- 🔎 **Honda:** links are Honda's own, found by search with matching titles,
  but Honda's CDN blocks scripted downloads, so I couldn't open them. They
  open fine in a browser. If the import says it can't fetch one, open the
  link, save the PDF, and choose the file (keep the link as the manual).
- ⬇️ **Download needed:** no public PDF link. Get the PDF from the maker's
  site and choose the file; leave the link field as the maker's page or
  blank.
- **km:** European edition, distances in km. Riders on miles will see
  converted numbers (10,000 km → 6,214 mi). Use a US edition instead if you
  have one.
